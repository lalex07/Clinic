## 2. Design rules — PASS

Audited against every rule in `CLAUDE.md`:

- **Gradients: ZERO** — no linear/radial/conic anywhere.
- **Glows/halos: ZERO** — no `backdrop-filter`, no `filter: blur`, no `filter: drop-shadow`, no `0 0`-origin glow shadows. The only `filter:` is the allowed color-normalization on doctor photos (`team.html`).

## 3. Accessibility — 4 issues

The baseline is good: one `<h1>` per page, `lang` attributes correct, all 42 `<img>` have alt text, QR alts are descriptive, skip-links on every page, `:focus-visible` outlines defined, `aria-current` on nav, and the mobile nav toggle has `aria-expanded` / `aria-label` / `aria-controls`. The gaps:

### 3.1 — [Medium] Looping animation ignores reduced-motion
`index.html` runs the hero `breathe` animation `6s … infinite`, but the `prefers-reduced-motion` guard lives in `assets/site.css` and only neutralizes `.reveal` + scroll-behavior. The inline breathe keyframes are **not** disabled, so motion-sensitive users get a continuous pulsing animation with no off-switch (WCAG 2.3.3).
**Fix:** add to `index.html`'s style block:
```css
@media (prefers-reduced-motion: reduce) {
  .breath-rings circle { animation: none; }
}
```

### 3.2 — [Medium] Low text contrast on `--ink-faint` and `--accent`
Measured against the cream background (`#FAF6EF`):

| Color | Ratio | WCAG AA (4.5:1 normal text) |
| --- | --- | --- |
| `--ink-faint` `#918A7C` | **3.18:1** | Fails (large text only) |
| `--accent` `#CC7A45` | **3.03:1** | Fails (large text only) |

`--ink-faint` is used for *small* supporting copy that should be readable: team-card bios (`team.html` `.team-note`, `.doc__sub` ~0.78–0.86rem), QR captions (`.qr-item__sub`), and service eyebrows. `--accent` is used for some small eyebrow/label text too. Both are fine for **large** display text (timeline years, big stat numbers ≥24px) but fall short for body-size text.
**Fix options:** darken `--ink-faint` toward ~`#736C5E` (hits 4.5:1) for text use — or reserve `--ink-faint`/`--accent` for large text only and switch small supporting copy to `--ink-soft` (`#5E584E`, 6.5:1, passes). `--primary`, `--ink`, `--ink-soft`, and white-on-primary all pass comfortably.

### 3.3 — [Medium] Decorative SVG icons not consistently hidden from screen readers
Only 45 of ~135 inline `<svg>` carry `aria-hidden`. Notably, **all 27 decorative icons in `services.html` are exposed** (calendar, ear, camera, person, chevron, etc.), as are icons elsewhere. Screen readers announce these as unlabeled graphics, and chevrons inside links pollute the link's accessible name.
**Fix:** add `aria-hidden="true" focusable="false"` to every purely-decorative inline SVG (anything that isn't conveying unique information). Mechanical, low-risk, big readability win for AT users.

### 3.4 — [Low] Heading-level skip on `locations.html`
`locations.html` jumps `<h1>` → `<h3>` (the 4 location-card titles aren't headings, and 全院區門診總表 is an `<h3>` with no `<h2>` above it). Minor structural gap.
**Fix:** promote the schedule heading to `<h2>`, and consider making the four location-card names headings (`<h2>`/`<h3>`) so the page outline reflects its structure.
