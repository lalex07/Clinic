隱私權政策

本頁說明大豐耳鼻喉科聯合診所網站如何處理造訪者的瀏覽資料。本網站本身不使用 cookie，也不會記錄可辨識個人身分的資料。

本網站會記錄少量匿名的瀏覽統計，用來了解哪些頁面與衛教內容對訪客有幫助。以下說明我們記錄什麼、不記錄什麼，以及這些資料如何保存。

我們記錄哪些瀏覽資料

每一筆紀錄包含以下欄位：

頁面路徑：您所瀏覽頁面的路徑（例如 /faq-q1.html）。網址中問號之後的查詢參數與井號之後的錨點都不會送出。

互動事件：僅區分三種——瀏覽頁面、開啟預約掛號視窗、閱讀衛教專欄文章。

裝置類型：依瀏覽器視窗寬度判斷為「手機」或「桌機」，不讀取裝置型號，也不記錄瀏覽器識別字串。

來源網站主機名：若您從其他網站連結進入，會記錄該網站的主機名（例如 www.google.com），不會記錄完整的來源網址。

單次造訪識別碼：由瀏覽器隨機產生、僅存放於分頁層級暫存空間（sessionStorage）的一組亂數，用來把同一次造訪中瀏覽的頁面串在一起。關閉分頁或瀏覽器後即消失，下次造訪會產生全新的一組，無法與您先前的造訪相互連結。

紀錄時間：由伺服器在收到紀錄時寫入的時間，瀏覽器無法指定。

記錄這些資料的目的

我們用這些統計了解哪些頁面與衛教主題對訪客有幫助、哪些說明不夠清楚，作為調整網站內容與版面的依據。這些資料不會用於廣告投放、行銷名單或任何個人化推播。

我們不會記錄的資料

本網站本身不使用 cookie，也不會在您的裝置寫入長期保存的識別碼。統計紀錄中不含 IP 位址、瀏覽器識別字串（User-Agent）、姓名、電話、電子郵件、病歷或任何就醫資料——資料表中沒有這些欄位。

我們不進行跨造訪、跨裝置或跨網站的追蹤，不建立個人輪廓，也不會將資料提供給廣告服務或作為商業交換。

本網站沒有線上填寫個人資料的表單；預約掛號一律以連結導向各院區的 LINE 官方帳號完成。站內搜尋則完全在您的瀏覽器中執行，您輸入的關鍵字不會傳送到伺服器。

資料的儲存與第三方服務

上述瀏覽統計儲存於第三方資料庫服務 Supabase。資料庫設有存取限制：網站端只能新增紀錄，無法讀取、修改或刪除；紀錄僅供診所的管理帳號查閱，刪除紀錄另需通過雙重驗證。

本網站代管於 GitHub Pages（GitHub 提供的靜態網站代管服務），本站所有頁面均由該服務傳送給您的瀏覽器。傳送頁面時，該服務會取得建立連線所需的資訊，其中包含您的 IP 位址；這屬於傳送網頁時無法避免的技術過程，與前述瀏覽統計是兩回事——送往 Supabase 的統計紀錄中沒有 IP 位址欄位。GitHub Pages 對這些連線資訊的處理方式，適用該服務自身的隱私政策。

本網站另使用下列第三方服務：Google Fonts 提供網頁字型、Google 地圖用於院區頁面的地圖顯示，以及 Cloudflare 的網站流量統計程式（不使用 cookie）——該程式目前尚未填入本網站的識別碼，因此還沒有產生任何可供我們查閱的統計。前述送往 Supabase 的瀏覽統計，其連線亦經由 Cloudflare 的節點轉送。您瀏覽時，瀏覽器會直接向這些服務發出請求，其資料處理方式適用各該服務自身的隱私政策。

診所另有一套須登入的內容編輯後台（網址 /admin/），僅供院內人員維護醫療團隊、最新消息與衛教專欄內容，未列於本網站選單，也不對外開放。該後台會向 jsDelivr（程式庫 CDN）載入連線資料庫所需的函式庫；本網站的一般頁面不會載入 jsDelivr，您瀏覽時瀏覽器也不會向其發出請求。

保存期限

瀏覽統計的保存期限為 90 天。前述每一筆原始瀏覽紀錄自寫入之日起保存 90 天，逾期予以刪除；清除作業由診所定期執行，目前未設定自動排程。保存期間內，這些紀錄僅用於前述的網站改善分析。

您的選擇

瀏覽統計屬於輔助功能。若您以內容封鎖工具或瀏覽器設定阻擋這類連線，網站的內容、院區資訊與預約連結一樣可以正常瀏覽與使用。若您的瀏覽器停用 JavaScript，這些統計就不會執行，也不會送出任何紀錄。單次造訪識別碼只存在於分頁層級的暫存空間，關閉分頁即會清除。

政策更新與聯絡我們

本政策內容如有調整，將直接更新於本頁。若您對本網站的資料使用有任何疑問，歡迎於門診時間致電各院區，或透過各院區的 LINE 官方帳號與我們聯繫。各院區電話請見院區・門診，LINE 預約與諮詢管道請見預約掛號。
